# qdai skill

This skill provides install and usage guidance for the upcoming Quick Deploy CLI (`qdai`).

## Install

The CLI is not published yet. When available, install it with:

```bash
npm install -g @quickdeployai/cli
```

## Verify installation

```bash
qdai --version
```

## Basic usage

Initialize a deploy configuration:

```bash
qdai init
```

Authenticate:

```bash
qdai login
```

Deploy the current project:

```bash
qdai deploy
```

## Notes

- Command names and package name are placeholders until the CLI is released.
- Update this skill once the Quick Deploy CLI is officially published.
